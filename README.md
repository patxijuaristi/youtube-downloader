# Youtube Video and Audio Auto Converter and Downloader 📽️🔽

This is a simple desktop program, developed with Python and Tkinter, using the automation library Selenium.

You can specifiy multiple keywords, and the program, opens a Chrome window, searches the keyword in the Youtube search, and downloads the video to the user computer in the preferred format: mp3 for audio or mp4 for video. Moreover, the user can download also the subtitles of the videos.

## Requirements

The used requirements are specified in the requierements.txt file. If you want to execute the *.py* script from python, you can install the dependencies with the next command:

```bash
pip install -r requirements.txt
```
